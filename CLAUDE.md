# GT72S OS — контракт агента

Це **існуючий проєкт**. Ніколи не створюй репозиторій заново.

## Перед будь-якою зміною коду прочитай

1. `docs/DECISIONS.md`
2. `docs/PROGRESS.md`
3. релевантні частини `docs/REQUIREMENTS.md`
4. існуючу реалізацію файлів, яких стосується зміна

## Пріоритет джерел істини

```
найновіше явне рішення користувача
  > docs/DECISIONS.md
  > docs/REQUIREMENTS.md
  > поточна реалізація
  > припущення моделі
```

Існуючий код **не є доказом правильності**. Якщо код суперечить актуальному
рішенню — це divergence, а не норма.

## Правила

- LOCKED-рішення — не питання. Не перепитувати.
- Змінювати інкрементально. Не переписувати файл, якщо вистачає локальної правки.
- Зберігати непов'язану роботу.
- Ніколи не повертати superseded-дизайн мовчки.
- Перевіряти `git status` / історію перед редагуванням.
- Валідувати саме те, що змінив.
- Оновлювати `docs/PROGRESS.md` після кожної суттєвої задачі.
- Оновлювати `docs/DECISIONS.md` одразу, коли змінюється архітектура.
- Ніколи не називати апаратну поведінку перевіреною без доказу з пристрою.

## Протокол ПЕРЕД кодом

```
CURRENT STATE:  гілка; релевантна існуюча реалізація; релевантні LOCKED
DELTA:          що саме треба змінити зараз
FILES TO TOUCH: конкретний мінімальний список
```

Тільки після цього редагувати.

## Протокол ПІСЛЯ коду

1. `git diff --stat`
2. Запустити релевантні перевірки.
3. Не називати перевіреним те, що фактично не запускалось.
4. Оновити `docs/PROGRESS.md`: DONE / CURRENT / BLOCKED / ON-DEVICE VALIDATION.
5. Оновити `docs/DECISIONS.md`, якщо змінилась архітектура.
6. Не переписувати історію progress — зберігати причини невдалих підходів.

## Обмеження середовища агента

Перевірено в цій сесії (2026-08-20):

| Інструмент | Стан | Наслідок |
|---|---|---|
| `nix`, `nix-instantiate` | **відсутній** | `nix flake check`, `nix eval`, `nixos-rebuild` **неможливі** |
| `cargo`, `rustc` | доступні | Rust-крейти можна перевіряти по-справжньому |
| `shellcheck` | відсутній | `pkgs/gt72/gt72.sh` не валідований |
| `safebooru.org` | HTTP 000 (заблоковано проксі) | SafeBooru API — UNVERIFIED EXTERNAL API |
| `cache.nixos.org` | HTTP 200 | сирці nixpkgs читаються, імена пакетів перевіряються |

Тому будь-яке твердження «збірка проходить» у цьому середовищі **неможливе**.
Максимум чесного формулювання: «статична перевірка пройшла, збірку не запускали».
